# QymCAD с ИИ-помощником

Переносимая версия для Windows 10/11 x64. Распакуйте папку полностью и запустите `qymcad.exe`. DLL должны лежать рядом.

1. Откройте «Окна» -> «ИИ-помощник».
2. Разверните «Подключение к API».
3. Укажите полный адрес API, оканчивающийся на `/chat/completions`, название модели и API-ключ. Поддерживается протокол chat/completions с текстовым JSON-ответом. Ключ вводится в программе; включать его в исходники не нужно.
4. Введите описание с размерами в миллиметрах и нажмите «Создать предпросмотр».
5. Проверьте форму (перетаскивание мышью вращает предпросмотр) и операции. Нажмите «Добавить деталь».
6. Ctrl+Z отменяет добавление. Размеры и операции остаются в дереве построения, можно редактировать их обычными инструментами QymCAD.

Пример: «Создай корпус 150 x 100 x 60 мм, сверху открытый, толщина стенок и дна 3 мм».

Можно продолжить: «Сделай высоту 80 мм». Будет построен новый вариант; после добавления старый остаётся в проекте. Для независимой детали нажмите «Начать новый диалог».

## Возможности первой версии

Параллелепипеды, цилиндры вдоль Z, сферы, перемещения, объединение, вычитание, пересечение и скругление всех рёбер. Из этих операций получаются корпуса, пластины, отверстия, втулки и несложные кронштейны. Не более 48 операций, размеры 0,05–2000 мм.

Произвольное редактирование существующей модели через чат, построение по фотографии, сложные поверхности и поворот тел в этой версии не поддерживаются. ИИ должен сообщать об ограничении, а не изображать успешное выполнение. Сложные рецепты иногда требуют повторного запроса.

## Подключение

Нужен свой API-ключ и доступ к выбранной модели либо собственный локальный сервер. Адрес задаётся полностью, например `http://127.0.0.1:1234/v1/chat/completions` для совместимого локального сервера. Для удалённого сервиса используйте HTTPS. Вводить API-ключ в адрес нельзя.

Настройки и ключ хранятся только до закрытия программы. Сервису передаются описание и последние шесть обменов сообщениями; остальная геометрия открытого проекта не передаётся. Кнопка отмены отбрасывает результат, но не гарантирует отмену уже отправленного запроса на сервере.

Геометрия проверяется перед добавлением: требуется одно корректное замкнутое твёрдое тело. Проверка геометрии не гарантирует, что ИИ правильно понял все размеры и назначение детали — сверяйте результат.
